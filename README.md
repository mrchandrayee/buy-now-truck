A delightful buy-now button with animated truck delivery interaction. Satisfying e-commerce microinteraction in pure HTML, CSS & JS.

---

## ✨ Features

- 🚚 Animated truck delivery on click
- 🛍️ Buy Now → Loading → Delivered states
- ✨ Smooth CSS transitions
- 📱 Responsive design
- ⚡ Zero dependencies
